# C Programs Library

Author: Ketakee Deshmukh

Programs Included:

1. Bubble Sort - Sorts elements of an array.
2. Linear Search - Searches an element in an array.
3. Factorial Recursion - Calculates factorial using recursion.
4. File I/O Example - Demonstrates file handling in C.
5. Matrix Multiplication - Multiplies two matrices.

Compilation:
gcc filename.c -o output

Run:
./output
